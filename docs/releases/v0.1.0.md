# Release Notes: v0.1.0

### What is Slopcheck Agent?
Slopcheck Agent is an AI-native npm supply-chain security tool designed to detect hallucinated, typosquatted, and suspicious packages before they enter your project. It acts as a proactive security layer evaluating risk via heuristic analysis (such as age, popularity, missing repositories, and similarities).

### What's included in v0.1.0
- **Core Risk Engine**: Calculates supply chain security signals.
- **Hallucination Detection**: Cross-references against official and community datasets.
- **Similarity & Impersonation Detection**: Identifies potential typosquatting or scope spoofing.
- **Heuristic Detectors**: Flagging missing repository metadata, abnormally low download activity, and extremely new package ages.
- **Explainability**: The `explain` command breaks down exact risk scores.
- **CI/CD Support**: Strict exit codes (0 = SAFE/SUSP, 1 = HIGH/CRIT, 2 = ERRORS) and JSON output natively.
- **Environment Diagnostics**: The `doctor` command validates network and datasets.

### Example usage
```bash
# Analyze a single package
slopcheck-agent check suspicious-package

# Analyze a package in CI/CD (JSON output)
slopcheck-agent check suspicious-package --json

# Scan all dependencies in a local package.json
slopcheck-agent scan package.json

# Explain the risk score calculation
slopcheck-agent explain suspicious-package
```

### Security model
Slopcheck detects **high-risk supply chain signals** and metadata anomalies that indicate an untrustworthy origin. It uses an **Anti-Dilution** scoring system where hard security signals (like exact hallucination matches) cannot be diluted by weak heuristic signals.

*Note: Slopcheck does NOT perform static/dynamic malware analysis on code or scan for CVEs.*

### Known limitations
- Does not currently scan for deep malware or source code anomalies.
- Does not check nested transitive dependencies recursively; it analyzes requested packages directly.
- GitHub and npm rate limits may occasionally result in PARTIAL assessments if the `GITHUB_TOKEN` is not set or network connectivity drops.

### Benchmark methodology
The deterministic benchmark infrastructure runs a predefined fixture dataset (including generated safe, suspicious, high-risk, and critical-risk packages) ensuring 93%+ F1 Score on Detection Accuracy prior to release. Caching is bounded and API failures are mocked during offline testing to guarantee reproducibility.

### Installation
Once published to npm, you can install the agent globally:

```bash
npm install -g slopcheck-agent
```
